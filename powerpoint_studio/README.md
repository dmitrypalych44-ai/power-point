## Что сделано

1. **Визуал приведён к брендбуку Лемана ПРО.** Использованы только корпоративные
   цвета брендбука: `#FFC100` (жёлтый), `#303738` (графит), `#FFFFFF` (белый).
   Производные оттенки — только тинты графита (`#3C4446`, `#454D4F`, `#5A6365`,
   `#8A6A00`, `#FFD35C`) для подложек, легенд и вторичных баров. Никаких сторонних
   цветов (зелёного, красного, синего) из исходной презентации.
2. **Фирменные принципы построения:** графитовый фон, жёлтая линия-акцент под
   заголовком, жёлтый кикер капсом, белые KPI-карточки с жёлтой верхней полосой,
   «домики» как маркеры легенды и этапов, кольцевые диаграммы, срез угла фотографии
   на обложке, логотип ЛЕМАНА ПРО, нумерация и источники мелким кеглем.
3. **Все цифры сохранены** — данные слайдов не менялись. Изменены только формулировки
   заголовков и подача.
4. **Проект «Стена» объединён**: вместо четырёх разрозненных страниц-рыб (свод,
   инициативы, метрики, «Декор») — единый блок из пяти слайдов с общей рамкой цифр:
   300 млн ₽ амбиция / +65 млн ₽ прирост / каналы / путь клиента / 8 инициатив /
   метрики и план. Отдельно сведены цифры свода:
   * амбиция проекта — 235 → 300 млн ₽ (+65 млн ₽);
   * подотделы 1210 / 1240 / 1250 — 280,7 → 315,5 млн ₽, эффект проекта +18,8
     (обои +12,8 · клей +3,9 · декор потолка +2,1);
   * плановый прирост без проекта +16,0 млн ₽ показан отдельным столбцом и не
     смешивается с эффектом «Стены».

## Что отдаём заказчику

`deliverables/Лемана_ПРО_Стратегия_Владивосток_2027.zip` — пакет для отправки:

* `.pptx` — редактируемая презентация (24 слайда, 16:9);
* `.pdf` — та же вёрстка с вложенными шрифтами (страховка, если LM Main не установлен);
* `Шрифты LM Main/` — 4 начертания для установки на рабочую машину;
* `ЧИТАЙ_МЕНЯ.txt` — как открыть, куда ставить шрифты, что проверить.

В pptx заполнены свойства документа (заголовок, тема, автор, язык), тема
презентации ссылается на LM Main — при установленном шрифте вёрстка совпадает
с превью 1:1.

## Технически

Презентация собрана кодом (`powerpoint_studio/`) сразу в двух бэкендах с одной
геометрией:

* `backends.PptxRenderer` — python-pptx, отдаёт `.pptx` с нативными фигурами,
  текстом и таблицами (всё редактируется в PowerPoint);
* `backends.PdfRenderer` — PyMuPDF, отдаёт PDF-пруф того же макета.

Шрифт в файле — **LM Main** (корпоративный). Так как сам LM Main проприетарный,
в комплекте идёт `LMMain-*.ttf` — метрически близкий аналог, на котором построена
вся геометрия слайдов; он же вложен в PDF. В pptx шрифт заявлен по имени, файлы
кладутся рядом с презентацией.

Встраивание шрифта внутрь pptx (`--embed-fonts`) выключено по умолчанию: по
ECMA-376 вложенные шрифты должны быть обфусцированы в формат ODTTF, иначе
PowerPoint предлагает «восстановить» файл. Флаг оставлен для стендовых проверок.

Пересобрать:

```bash
python -m venv .venv && .venv/bin/pip install python-pptx pymupdf pillow fonttools brotli
.venv/bin/python powerpoint_studio/build_deck.py --png
```
